# Payout Lab Atom 2.0 Logo Pack

An original minimal atom mark for Payout Lab. Every asset has a transparent background and uses exactly one center nucleus with three uninterrupted orbital rings.

## Variants

| Folder | Colors | Recommended use |
| --- | --- | --- |
| `black` | Black | Light backgrounds and print |
| `white` | White | Dark backgrounds and overlays |
| `forest-gold` | Forest green + dividend gold | Primary Payout Lab identity |
| `ion-gold` | Ion green + dividend gold | Bright digital and dark-mode accent |
| `mint-ion` | Mint + ion green | Dark-mode header and app surfaces |

Each folder contains an SVG master and transparent PNGs at 16, 32, 64, 128, 256, 512, and 1024 pixels.

## Recommended defaults

- Website header and README: SVG `forest-gold`
- Browser favicon: 32px or 64px PNG `forest-gold`
- Home-screen/app icon source: 1024px PNG `forest-gold`
- Single-color printing: SVG `black`
- Dark photographic backgrounds: SVG `white`

The SVG files are the master artwork and should be preferred whenever the destination supports vector images.
