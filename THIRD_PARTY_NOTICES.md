## QR Code generator library (Project Nayuki)

`js/vendor/qrcodegen.js` is the TypeScript-compiled build of Project Nayuki's QR Code generator library, taken unmodified (apart from dropping the `"use strict"` line, since ES modules are already strict) from the npm package `nayuki-qr-code-generator` 1.8.0. It runs entirely in the browser and makes no network requests.
